This directory contains upstream runtime assets **and their TypeScript source**, plus the original `upstream-index.html`, README, format documentation and package/TypeScript manifests. `UPSTREAM.json` records source-file checksums before integration patches. `scripts/vendor_oxview.py` reproduces the pinned distribution.

Lazarus modifications:
- `index.html` disables analytics and external structure import, loads local bridge/styles, adds a restrictive CSP, and omits the editing keybindings.
- `dist/main.js` restricts upstream message handling to the same-origin parent.
- `lazarus-bridge.js` and `lazarus.css` are integration additions, licensed GPL-3.0-or-later. They hide editing UI and expose a narrow, origin-checked interface for viewing a supplied DNA sequence, optional generated complement, camera controls and sequence highlighting.

The viewer is a separate application inside a same-origin iframe. DNA sequences are obtained by the Lazarus UI from the existing private artifact API and passed in memory. The frame makes no network requests for archive data and does not mutate or save archives. Modeling coordinates are idealized geometry generated by oxView; no claim of molecular-dynamics prediction or physical synthesis is made.

Reference: Erik Poppleton et al., oxView, https://doi.org/10.1093/nar/gkaa417; https://doi.org/10.1038/s41596-022-00688-5.
